对于任何一个不封闭的序数记号或非序列型号(若声明不封闭除外)

\section{展开与计算}
对于 $\alpha,\beta\in On\cup\Pi_1$ 有:
\begin{itemize}
  \item 加法：
  \begin{itemize}
    \item $\alpha+0=\alpha$
    \item $(\alpha+\beta,n)=\alpha+expand(\beta,n)$
  \end{itemize}
  \item 乘法：
  \begin{itemize}
    \item $\alpha 0=0$
    \item $expand(\alpha\beta,n)=\alpha expand(\beta,n)$
  \end{itemize}
  \item 指数：
  \begin{itemize}
    \item $\alpha^0=1$
    \item $expand(\alpha^{\beta},n)=\alpha^{expand(\beta,n)}$
  \end{itemize}
\end{itemize}
